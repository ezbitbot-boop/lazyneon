# 한국어 동사 선택

한국어 설명·보고·답변을 작성할 때만 읽는다. 아래는 공개 언어 규범과 일반적인 한국어 용법을 바탕으로 직접 작성한 편집 지침이다. 인용문, 법률 용어, 증거 원문은 고치지 않는다. 뜻과 행위 주체를 보존하는 일이 문장 단축보다 우선한다.

- 실제 동작을 쓴다. 파일은 저장·읽기·수정·삭제하고 설정은 지정·등록한다. 무엇을 했는지 없는 ‘처리를 진행했다’는 피한다.
- ‘검토를 수행했다’는 ‘검토했다’, ‘결정을 내렸다’는 ‘결정했다’로 줄인다. ‘영향을 주다’는 문맥에 따라 ‘늦추다’, ‘늘리다’ 등으로 구체화한다. 인과관계가 확인되지 않았다면 단정하지 않는다.
- ‘~를 통해’가 수단을 흐리면 도구나 행위를 바로 밝힌다. ‘검색을 통해 항목을 찾았다’ → ‘항목을 검색했다’. 실제 경로나 매개를 뜻하는 ‘관을 통해 흐른다’는 유지한다.
- ‘~에 있어서’는 대상을 분명히 적는다. ‘설계에 있어서 중요한 조건’ → ‘설계의 중요한 조건’. 존재를 뜻하는 ‘서랍에 있어서’까지 기계적으로 바꾸지 않는다.
- ‘~하는 것이 필요하다’는 ‘~해야 한다’로 쓴다. 권고이면 ‘~하는 편이 좋다’로 적어 의무와 구별한다.
- 주체를 알면 능동문을 우선한다. ‘관리자에 의해 권한이 변경되었다’ → ‘관리자가 권한을 바꿨다’. 주체가 불명확하거나 결과가 중심이면 피동문도 쓴다. 없는 행위자를 만들지 않는다.
- 겹피동 ‘~되어지다’는 ‘~되다’ 또는 주체가 있는 동사로 고친다. ‘기록되어졌다’ → ‘기록됐다’. 모든 ‘되다’를 금지하지 않는다.
- 영어 have를 따라 ‘가지다’를 붙이지 않는다. ‘차이를 가진다’ → ‘다르다’, ‘회의를 가진다’ → ‘회의한다’, ‘기능을 가지고 있다’ → ‘기능이 있다’. 소유·지참의 실제 뜻은 유지한다.
- 추상 명사 뒤에 동사를 덧붙이기 전에 누가 무엇을 바꿨는지 확인한다. 같은 동사를 반복해도 뜻이 정확하면 억지로 유의어를 찾지 않는다.
