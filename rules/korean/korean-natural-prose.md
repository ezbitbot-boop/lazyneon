# 자연스러운 한국어 산문

한국어 답변·문서·보고서 초안을 만들 때만 읽는다. 공개 언어 규범과 일반적인 글쓰기 원칙을 바탕으로 직접 작성한 편집 지침이다. 인용·법률·증거 자료의 정확성을 문체보다 우선한다.

- 첫 문장에 결과나 핵심을 쓴다. ‘좋은 질문입니다’, ‘지금부터 살펴보겠습니다’ 같은 도입과 ‘도움이 되셨길 바랍니다’, ‘결론적으로 정리하면’ 같은 반복 마무리를 붙이지 않는다.
- 한 문장에는 중심 판단 하나를 둔다. 조건과 예외가 겹치면 문장을 나눈다. 무조건 짧게 끊지 말고 짧은 결과 문장 뒤에 필요한 설명을 잇는다. 문단은 한 주제로 묶고 4문장 이내를 기본으로 한다.
- 조사와 종결어미를 자연스럽게 잇는다. ‘~이며’만 반복하거나 모든 문장을 명사형으로 끝내지 않는다. 문장 길이 제한 때문에 법적 조건이나 불확실성을 생략하지 않는다.
- 장식 이모지와 장식용 볼드는 쓰지 않는다. 제목·표·목록은 비교나 순서를 이해하는 데 필요한 만큼 쓴다. 본문을 잘게 쪼개 카드처럼 늘어놓지 않는다.
- ‘혁신적인’, ‘다면적인’, ‘심리스한’, ‘중추적인’ 같은 AI 상투어 대신 확인한 기능·차이·결과를 쓴다. 근거 없는 칭찬과 성과 단정은 빼고 실패·미확인 사항을 정확히 적는다.
- 숫자는 같은 문서에서 표기를 맞춘다. 천 단위 구분은 ‘12,000’처럼 쓰되 식별자·버전·원문 수치는 그대로 둔다. 단위 명사는 띄어 쓰는 것을 기본으로 하며 숫자와 붙여 쓰는 허용 표기도 문서 안에서 통일한다. ‘세 개’, ‘3개’, ‘10분’의 표기를 목적에 맞게 정한다.
- 측정값에는 단위와 필요한 기준 시점을 쓴다. SI 단위 기호는 ‘5 kg’, ‘20 ms’처럼 표기하고 제품명·API 값은 원래 표기를 따른다. 비율과 퍼센트포인트를 구별한다. 근거 없는 반올림·정밀도·단위 환산을 하지 않는다.
- 파일을 만들거나 수정한 턴은 마지막에 산출물을 열거나 실행하는 짧은 안내 한 줄을 둔다: ‘report.md를 열어 변경 내용을 확인하세요.’ 이미 전달한 결과를 다시 요약하거나 선택하지 않은 후속 작업을 권하지 않는다.
